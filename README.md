Barbershop Management System 💈

A console-based C application designed for managing barbershop services, transactions, and role-based authentication (Admin & Cashier) as part of the CEP-CCIT Faculty of Engineering, Universitas Indonesia curriculum.

📖 Project Overview

This project implements a structured C-programming solution to streamline daily barbershop operations. It features secure credential-based login mechanics separating administrative management from cashier operations, complete with transaction calculations and dynamic service handling.

Key Features & Architecture:

- Role-Based Authentication: Distinct access portals for Admin (managing services) and Cashier (handling customer transactions).

- Service Management (Admin): Full CRUD capabilities allowing administrators to view, add, edit, delete, and search barbershop services.

- Point of Sales / Cashier System: Interactive ordering mechanism supporting multi-service selection, real-time total calculation, and automated change computation.

- In-Memory Struct Implementation: Utilizes C structures (struct Layanan) and arrays to handle service catalogues efficiently.

🛠️ System Specifications

- Language: C (Standard C / ANSI C)

- Development Environment: GCC / Dev-C++ / Visual Studio Code

- Core Data Structures: Structs, Arrays, Control Flow (Loops, Switch-Cases), Functions, and String Manipulation (string.h).
